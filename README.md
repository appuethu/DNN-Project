
# HeartGuard+ (Research-style demo)

This project is a research-style demo of a Deep Neural Network (DNN) that predicts heart disease risk
using a hybrid input of clinical features and lifestyle embeddings.

**Contents**
- data/heart_clinical_synthetic.csv - synthetic clinical data (Cleveland-like)
- data/lifestyle_synthetic.csv - synthetic lifestyle features (steps, sleep, stress, BMI...)
- data/heart_combined_synthetic.csv - merged dataset used by demo
- model/heartguard_dnn.py - model build + training script (Keras)
- model/artifacts/ - created by training (scalers, best_model.h5)
- app/app.py - Streamlit web app with SHAP explainability integrated
- requirements.txt - Python dependencies

**How to use**
1. Create a Python virtualenv and install packages:
   ```bash
   python -m venv venv
   source venv/bin/activate   # on Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Train the model (optional, recommended for realistic predictions):
   ```bash
   python model/heartguard_dnn.py
   ```
   This will save scalers and a trained model to `model/artifacts/`.
3. Run the Streamlit app:
   ```bash
   streamlit run app/app.py
   ```

**Notes**
- The dataset included is synthetic for demonstration. Replace with real clinical + lifestyle labeled data for research-quality results.
- The Streamlit app will still run if the model is not trained; SHAP explanation requires the trained model and saved scalers.
